# 🧮 On-Screen Calculator

A fully interactive on-screen calculator built with **HTML, CSS, and JavaScript**.

This project is the final project of my current learning phase and brings together the JavaScript, DOM manipulation, event handling, CSS, and problem-solving concepts I've learned so far.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔄 Clear / reset functionality
* 🖥️ Interactive on-screen buttons
* ⌨️ Keyboard support
* ⚠️ Basic handling of invalid calculations

## 🛠️ Built With

* **HTML5** — Structure
* **CSS3** — Styling and layout
* **JavaScript** — Calculator logic and DOM interaction

## 🎯 Project Goal

The goal of this project was not only to create a working calculator, but to put the JavaScript fundamentals I've learned into practice by building something interactive from scratch.

Instead of relying on a calculator library or external code, the calculator logic and user interactions are implemented using vanilla JavaScript.
